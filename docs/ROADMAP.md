# Build roadmap

## Milestone 0: repository and reproducible pilot

- [x] Canonical concept collection, validated targets, original draft entries.
- [x] Local interactive exploration, comparison and guided context exercise.
- [x] Self-contained offline build and printable edition.
- [x] Validation tests and CI configuration.
- [x] Remote GitHub repository created; starter uploaded.
- [ ] Review browser accessibility with keyboard and screen reader users.

## Milestone 1: editorial foundation

The initial AI-assisted source comparison, references and rights notes are complete for the five entries. Independent specialist review is pending. Test overlap, polysemy, disputed senses and nonbinary distinctions. Ask whether the contract can express them before growing the collection to 30 concepts.

## Milestone 2: usefulness

Run the small comparison study in EVALUATION.md. Revise based on errors and user explanations, including where visuals mislead. Record changes. Treat a positive pilot as preliminary evidence.

## Milestone 3: durable publication

Add a reviewed import pipeline; versioned releases and checksums; independently tested platform compatibility; accessible print proofs; book navigation and page references. Decide code/content licenses, institutional home, brand, contributor policy and distribution model. USB sale is a distribution option, not a current dependency.

## Downstream research

Consilient educational pathways; cross-domain concept discovery; faithful abstract visualizations; natural-process analogies. These remain research ambitions, separate from release acceptance criteria. Neither blank map positions nor analogies prove new concepts or structures of reality.
