# Pilot acceptance and remaining review

## Automated and editorial gates

- Five senses retain stable IDs, contextual scope, examples, counterexamples, relation notes, references and visible draft status.
- Multilingual fields preserve expression identity, language, direction, usage and cultural notes; exact-equivalence claims require explicit review metadata.
- Guided inquiry includes separate and coexisting ambiguity/vagueness, pragmatic inference and uncertainty.
- Web, downloaded offline and script-free printable editions derive from the same records and scenarios.
- Validation, regression tests, TypeScript compilation and reproducible build checks pass.

## Human gates

Independent specialist review, representative user sessions, assistive-technology testing, actual printer proofing and cross-platform testing remain necessary. Automated Chromium tests cover one engine and environment only. Source comparison cannot substitute for those reviews.

Suggested formative session: give a participant a new instruction, ask which difficulty they notice, let them inspect the atlas, then ask for a clearer explanation and question. Record accuracy, time, confidence and remaining misconceptions. Use matched content and counterbalanced examples before attributing a gain to the organization.
