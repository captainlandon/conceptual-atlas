# Small pilot protocol

Recruit a small, varied convenience sample, for example 6–10 people. This is formative testing, not population-level proof. Give each participant matched unfamiliar scenarios using the atlas and ordinary definitions, counterbalancing tool order and scenario assignment. Use the same concept information where possible to distinguish organization effects from added content effects.

Before testing, set a rubric: correct distinction, explanation quality, appropriate uncertainty, and application to a new scenario. Capture time alongside accuracy and confidence. Faster wrong answers are not improvement. Ask which relationship or visual helped, confused or imposed an interpretation. Include a delayed transfer task if feasible.

Do not use the worked 'Fine' example as the main outcome task. Use unseen examples. Preserve anonymized observations only with participants' agreement; the software itself records nothing. Record limitations, changes and failures before expanding.
