# Preservation and independence

Preserve source JSON, source code, documentation, generated offline HTML, printable HTML and release checksums together. Keep redundant copies on different media and in different locations. A USB alone is vulnerable to loss, deterioration, incompatible hardware and obsolete browsers. Periodically verify and migrate copies; no medium guarantees permanence.

The plain-text concept records remain readable even if this interface becomes obsolete. Paper provides use without electricity, while preserving relationships through stable IDs and written cross-references. Each future edition should include date/version, source register, editorial status, index and instructions for reconstructing the collection.

For a release, run validation and tests, rebuild, verify on the target devices without network access, inspect printed output, then archive the bundle. The pilot does not yet include a dedicated desktop installer, mobile app, content updater or professionally typeset book.
